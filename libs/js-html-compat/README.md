# js-html-compat

Migration aid from `js.html` (Haxe standard library) to [js-std](https://github.com/kLabz/js-std): every `js.html` type with a counterpart in `js-window-api` becomes a deprecated typedef to it, so existing code compiles and each use warns with the new name (`js.html.DivElement` → `js.web.html.HTMLDivElement`).

`js.Browser` is replaced too, typed with js-std types. `js.html` types without a counterpart (obsolete or worker-only APIs) are left to the standard library.

Generated by [js-std](https://github.com/kLabz/js-std). Do not edit by hand.

Depends on `js-window-api`. Meant to be dropped once the warnings are gone.
